# 📜 Changelog

All notable changes to the **Momentum Learning** project are documented in this file.

## [1.0.0] - 2026-08-14

### Added
- **Core Platform Launch**: Initial release of Momentum Learning full-stack application.
- **Backend Architecture**: Spring Boot 4.1.0 backend with Java 21, Spring Data JPA, and MySQL 8.
- **Authentication & Security**: JWT stateless token authentication, Spring Security filter chain, and BCrypt password encryption.
- **Topics & Subtopics Engine**: Topic hierarchy management, subtopic progress calculation, and BLOB file document storage.
- **LeetCode Practice Logger**: Daily problem logging with difficulty tags, streak tracking, whiteboarding photos, and code screenshots.
- **Analytics & Dashboard**: Interactive monthly activity calendar heatmap, recent activity streams, and summary key metrics.
- **Admin Module**: Admin management dashboard for user account controls (role elevation, account status updates, deletion) and platform-wide analytics.
- **Comprehensive Documentation**: Complete REST API specifications, Database ERD and schemas, Production deployment guide, and Software Architecture & Maintainability standards.
